# Treino de Engenharia de Software

## Objetivo

Recuperar e aprofundar minha capacidade de:

- raciocínio lógico;
- resolução de problemas;
- programação;
- engenharia de software;
- arquitetura;
- leitura técnica;
- tomada de decisão.

Também desenvolver a capacidade de
observar e interpretar o mercado de software.

## Duração

12 semanas.

## Estrutura

4 ciclos de 3 semanas.

Cada ciclo aumenta gradualmente
a complexidade dos problemas.

## Princípio

Primeiro penso.

Depois pesquiso.

Depois peço ajuda.

Depois valido.
